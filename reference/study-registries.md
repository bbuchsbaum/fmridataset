# Study link and table accessors

Study link and table accessors

## Usage

``` r
study_links(x)

study_link(x, name)

study_tables(x)

study_table(x, name)

events(x, name = "events")
```

## Arguments

- x:

  An `fmri_study` or filtered view.

- name:

  Stable link or table name.

## Value

A registry or one descriptor/table.
