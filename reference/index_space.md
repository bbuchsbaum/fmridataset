# Construct a generic indexed feature space

Construct a generic indexed feature space

## Usage

``` r
index_space(n, ids = NULL, namespace = NULL, data = NULL)
```

## Arguments

- n:

  Number of features.

- ids:

  Optional stable feature IDs.

- namespace:

  Namespace used for generated IDs.

- data:

  Optional feature metadata.

## Value

An `index_space`.
