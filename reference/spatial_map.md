# Recover a spatial map for one observation

Recover a spatial map for one observation

## Usage

``` r
spatial_map(x, observation, assay = active_assay(x))
```

## Arguments

- x:

  An `fmri_frame` or view.

- observation:

  Observation ID or one integer position.

- assay:

  Assay name.

## Value

A reconstructed spatial object.
